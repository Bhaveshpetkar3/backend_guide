# Getting Started

This is an example guide file. To add a new guide:

1. Create a new `.md` file in the `_guides/` directory
2. Add the front matter block at the top (see this file for reference)
3. Write your content in Markdown
4. Commit and push — GitHub Pages will build and deploy automatically

## Front Matter Template

```yaml
---
layout: guide
title: "Your Guide Title"
subtitle: "A short description"
nav_title: Short Nav Name
tags: [Tag1, Tag2]
---
```
